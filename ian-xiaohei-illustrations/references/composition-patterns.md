# 构图模式指南（单体 / 双人 / 场景）

总原则
- 一张图只表达一个核心动作或隐喻。
- 主体占画面 40%–60%，画面留白明显。
- 线条与风格在所有构图中保持一致。

常见结构类型（可在 shot list 中指定）
1. Single character — Selected IP
   - 场景：所选 IP 独自承担动作（牵线、举牌、拿花、读书）
   - 构图提示：角色置于画面左/中，动作明确；保留单色强调（喙/脚/小道具为黄色）

2. Single character — Cat
   - 场景：猫承担状态/评价（观察、坐着思考、端茶）
   - 构图提示：猫脸部斑块与眼神要明显，姿态死板/冷淡，适用少量粉色/淡蓝作为装饰

3. Duo scene — Cat + Duck
   - 场景：一动一静（Duck 更主动、Cat 更冷淡）
   - 构图提示：确保尺度匹配，把两角色放在相近视高线上，或用前后关系表达“承接/对比”
   - 互动样例：Duck 指着一个钩子/门，Cat 在旁边淡定记录

4. Workflow / Path / Handoff （承接路径）
   - 场景：用一条主线（黄色/橙色）或箭头表现流程，角色在路径节点上做关键动作
   - 构图提示：单条主线清晰，角色动作对应节点（动词明确）

5. Metaphor / Object substitution（概念隐喻）
   - 场景：把抽象概念用一个低科技、荒诞但成立的物件表现（例如：筛子、漏斗、桥）
   - 构图提示：让角色与物件直接互动（搬、拉、盖章等），并保持画面清爽

说明
- 每个样式均强调“角色必须承担核心动作”。如果去掉角色图仍能成立，说明角色成为装饰，需调整提示词。

反复刻规则（旧案例与迁移）
- 项目中保留了若干旧示例供风格校准用途（assets/examples/）。这些示例中曾使用“原始角色/历史角色”做参考。请勿直接复刻旧构图；在生成时用所选 IP（{IP=cat|duck|fusion}）重新发明隐喻。

- 以下为历史上常见的构图套路（仅供识别与避重用）：
  - 传送带两个断点
  - 牵线或操作判断杆的角色
  - 变成漏斗分拣流量/信任/转化的场景
  - 切素材（示例：素材鱼）
  - 牵承接路径的示例
  - 拉三层信息源的布局
  - 多角色分别承担喇叭/搭桥/开门等动作
  - 盖章/话术工具箱样式
  - 举牌查看“常见坑路径”的构图

- 使用历史示例作风格校准时，务必把“历史角色”替换为所选 IP 并重构隐喻细节（比例、动作、主物件、标签），避免直接套用旧物件与动作。
