# 小黑 IP（已替换）

## 角色定义（替换稿：你的 IP — 猫 / 鸭 / 合体）

本文件定义默认视觉 IP（你的 IP），用于替换原 Skill 中的“小黑”角色。参考图（images）：图1 = 猫，图2 = 鸭，图3/4 = 猫与鸭的合体 / 场景混合图。使用时可选图号或在 prompt 中指定 {IP=cat}、{IP=duck} 或 {IP=fusion}。

### 概述
你的 IP 是 Ian 风格正文配图里的固定视觉角色群。它们不是贴纸、不是可爱周边，而是“正在认真参与系统运转”的荒诞执行者。每张图默认必须出现至少一个 IP（猫、鸭或二者合体/协作），并承担图中核心动作或语义工作。

一句话：把文章里的一个关键认知动作交给“猫 / 鸭 / 合体”来做，而不是把它作为装饰。

---

### 外形（视觉特征）
- 体色：主体通常为白色平涂（身体），带黑色斑块或黑色线条细节（例如猫的耳朵、脸部斑块、鸭的眼罩等）。  
- 眼睛：白点眼或细线状闭眼/半闭表现，神情偏冷静、淡定或略带无奈（deadpan）。  
- 轮廓线：中等粗的黑色手绘轮廓，线条略有抖动/毛边、收尾圆润（非矢量光滑）。  
- 四肢与动作：用细线表示腿/翅膀/尾巴，姿态强调“在做事”（牵、搬、按、切、连接、盖章等）。  
- 局部色块：黄色用于喙、脚、光晕或强调点；粉色/肉色用于食物/蛋糕/花瓣；淡蓝作小配饰色。色彩克制、数量少。

### 性格与表情
- 冷静认真，做事带点荒诞，既不卖萌也不搞夸张表情。  
- 有一点低调的幽默感：看起来像认真上班的怪物工人。  
- 在场景中通常承担功能性职责（例如：搬运素材、牵线、当筛选器、举警告牌、盖章）。

### 常见职责（可在 prompt 中指定）
- 搬运素材 / 切割素材  
- 拉线 / 汇聚信息源  
- 卡在断点 / 操作判断杆  
- 变为筛选漏斗 / 搭桥 / 搬砖 / 记录  
- 扮演承接路径中的关键节点  
- 作为前后对比的一侧角色（例如：左混乱、右稳定）

### 禁止项（必须严格遵守）
- 不要把 IP 画成过度可爱、圆润的吉祥物风格。  
- 不要给复杂服装、花哨装饰或商业光泽（高光/渐变/阴影）使其变精致。  
- 不要把角色仅放在角落做装饰 —— 若去掉角色图仍成立，说明角色太装饰。  
- 不要给角色复杂表情或过多细节（保持简洁的白点眼/细线眼）。  

### 可变体与使用规则
- 单角色图：用图1（猫）或图2（鸭）承担全部动作。  
- 双角色图：猫和鸭分工（例如：猫负责判断/观察，鸭负责搬运/庆祝）。  
- 合体/场景：使用图3/4 的合体或场景图来表达角色协作或更复杂的情境。合体形象（{IP=fusion}）必须遵循参考比例（见下文）。  
- Prompt 变量：在 prompt 中支持 {IP=cat} / {IP=duck} / {IP=fusion}，并在生成时把“Skill 的默认小黑”替换为指定 IP。

### 合体比例（Fusion proportions）
当选择合体形象 {IP=fusion} 时，合体角色必须遵循参考图（image 8）的体型与比例：以猫为主体体块（总体占比为主），鸭的头/喙/翅膀作为附属部件嵌入或站立于猫体上，整体视觉保持猫体为主、鸭元素为辅的比例关系。不要把鸭画得与猫等大或超过猫的主体块；合体应看起来是“同一体型语言”的混合体，而非两个同等大小角色的并列。生成与编辑时应把 image 8 作为比例参考。

### 判断标准（QA）
生成后如果出现以下问题应重生成或局部编辑：
- 角色变得“太可爱/卡哇伊/精致”，或线条变得过光滑。  
- 颜色过度饱和或引入过多新颜色（超过 2 个强调色）。  
- 角色没有承担核心动作，或仅作背景装饰。  
- 背景出现渐变、纸纹、阴影或复杂纹理。  
- 中文标注过多或成为大段文本（标注建议 ≤5 个短词）。
