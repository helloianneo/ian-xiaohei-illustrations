# 竖版构图模式

先根据正文选择一种主结构。结构是画面骨架，不要把结构名称写到图上，也不要把所有内容画成规整 PPT。

## 小红书首图

首图的任务是让用户在缩略图和快速滑动中立即知道“这是什么、为什么值得看”。只保留一个短钩子、一个可信事实或结果和一个视觉动作。

- 标题通常位于上方或左上，保持短、粗、可读，不把整段口播稿塞进首图。
- 可放一个结果数字、项目名或标签作为证据，但不要同时堆满星数、功能和使用教程。
- 鲸鱼娘通常占 20%–30%，放在右下或侧边回应标题；道具只能辅助标题关系。
- 首图和内容页共享边框、底刷、颜色和角色身份，但不必复制同一姿势。

## 小红书轮播页

轮播页是独立页面的连续叙事，不是把单张长海报切片。每页先写一句“这一页看完要记住什么”，再决定文字和画面。

推荐页面职责：

1. 封面：痛点/结果钩子 + 项目名或一个事实。
2. 问题：用户为什么需要它，保留一个具体场景。
3. 亮点：2–3 个最有差异的功能，用短句和动作表达。
4. 证据：截图、数据、Stars、前后变化或使用步骤，来源要清楚。
5. 判断：适合谁、注意什么或作者体验。
6. 结尾：总结或用户提供的 CTA，可选。

不是每组都要六页。主题不足时使用四页或五页；不要为凑页数重复同一功能。

页面布局可以采用“标题区 + 主内容区 + 小角色回应”的结构。内容页鲸鱼娘通常占 8%–18%，必要时只出现半身、侧脸、手部或尾巴的一部分，确保正文和截图成为主角。

## 内容卡片模式

适合项目介绍、工具推荐、体验总结、特色亮点、数据变化和带 CTA 的中文正文配图。

建议关系：

- 上方：醒目的但不过大的主标题，下面接一条短副标题或事实说明。
- 中部：2–4 个不等大的手绘内容区，可是数据框、观点框、短列表、气泡或带下划线的正文区域。
- 右侧或右下：一位较小的鲸鱼娘，通常占 20%–35%，用神态和动作回应内容，而不是遮住文字。
- 底部：可选问题、互动 CTA 或一句结果；如果正文没有 CTA，不要擅自添加营销话术。

内容区可以有边框、淡蓝底刷、手绘下划线、箭头和小涂鸦，但必须形成阅读层级。不要做等宽卡片、仪表盘、九宫格、图标清单或完整表格。

可借鉴 `assets/layout-reference/content-card-spirit.png` 的气质：文字层级较丰富，角色在右下与内容对话，整体不对称，有气泡和少量节奏点。不要复制它的具体标题、人物姿势或道具。

## 场景隐喻模式

适合一个判断、一个阻力、一个前后变化或一个系统局部。用一个低科技物件承载抽象关系，例如潮汐桶、回声贝壳、筛网、抽屉、浮桥、漏水的水箱或工作台。鲸鱼娘需要对物件做具体动作，文字只保留必要短标签或一句判断。

可以使用：

- 单一概念隐喻
- 一个连续动作表达前后变化
- 一条弯曲路径表达输入到结果
- 一个局部装置表达反馈或阻力
- 一个角色状态表达卡住、选择、焦虑或松开

阀门、闸门、磁盘、垃圾文件等道具只是关系载体，除非主题就是它们，否则不能放大成第二个主角。

## 隐喻生成公式

```text
抽象关系 → 物理动作 → 低科技物件 → 鲸鱼娘的动作 → 一个可见结果
```

## 共同的反 PPT 规则

- 反对的是僵硬的等宽网格、仪表盘、流程节点和图标堆砌，不是所有文字区域。
- 文字区可以不规则、有手绘边框、气泡和下划线，但要有主次和留白。
- 不让每个信息点都拥有一个图标和同样大小的卡片。
- 不用大量箭头解释每一步，优先用接触、重力、水流、缺口、门和动作表达方向。
- 不能为了突出角色而删掉用户明确要求的标题、项目介绍或数据。

## 装饰预算

默认从深蓝边框、淡蓝标题底刷、气泡、手绘箭头、纸张质感、小鲸鱼涂鸦中选少数几类。小鲸鱼涂鸦最多一到两个且不能重复印在道具上；装饰不服务于阅读或情绪就删掉.
