# 鲸鱼娘与小鲸鱼 IP

## 参考资产

生成角色时必须传入实际图片，不得只写“蓝色鲸鱼娘”作为提示词。

- `assets/whale-girl-reference/whale-girl-neutral.jpg`：主身份和服装参考，默认使用。
- `assets/whale-girl-reference/whale-girl-smile.jpg`：闭眼笑和明亮情绪，需要笑脸时使用。
- `assets/whale-girl-reference/whale-girl-wave.jpg`：挥手、手臂动作和互动情绪，需要挥手或招呼时使用。

每次默认只传一张 neutral。只有动作或表情确实需要时，才增加 smile 或 wave，不要求每次重新读取全部参考图。

## 鲸鱼娘身份锚点

这是一位精致 Q 版蓝色鲸鱼娘：

- 深蓝到蓝色的长发，头顶小蓝色发卷。
- 白色蕾丝女仆发箍，侧边蓝色蝴蝶结。
- 鲸鱼鳍形耳朵，蓝色大眼睛，圆润但精致的脸。
- 深蓝色女仆裙，白色蕾丝领口和白色围裙。
- 蓝色鲸鱼尾巴，尾巴内侧有蓝灰层次。

不要替换成普通海妖、蓝色猫娘、泳装角色、机械娘、兽耳女仆或没有尾巴的普通二次元女孩。不要新增大量徽章、蝴蝶结、海洋饰品或鲸鱼贴纸。

## 角色必须做事

根据内容选择动作：写、拉、扛、捞、推、筛、拧、守、观察、修补、搬运、整理、指向、回应或把对象交给下一处。

生成前必须能回答：

> 鲸鱼娘正在对什么东西做什么，因此读者看见了什么关系？

如果只能写“她站着微笑”，说明角色没有参与内容，应重做构图。

## 小鲸鱼数量和作用

- 默认 0–1 个小鲸鱼。
- 群体、尺度、水流、反馈、陪伴、结果或连续动作确实需要时，可以增加到 2–4 个，必要时再按画面需要增加。
- 小鲸鱼可以大小不同、方向不同、动作不同，形成节奏或因果关系。
- 每只小鲸鱼都应承担身份、动作、状态、尺度、反馈或情绪作用。
- 不把小鲸鱼当作 Logo，不反复印在所有物件上。

## 禁止结果

- 多个鲸鱼娘抢主体。
- 鲸鱼娘变成贴在信息卡旁边的 Logo 或大型站立立绘。
- 人物全身草稿化、模糊、脸手不可辨认。
- 无关的性感化、低龄化、机械化或复杂海洋装饰。
- 只剩通用蓝色角色，无法看出女仆装、发箍、蝴蝶结、鲸鱼耳鳍和尾巴。
