# 鲸鱼娘 IP 与角色事件

## 角色定位

鲸鱼娘是正文事件中的行动者和解释者，不是站在画面边缘的装饰角色。她应当用一个明确动作把文章里的关系、阻力、选择或结果变得可见。

默认风格是精致 Q 版为主、轻手绘为辅。人物可以有圆润的 Q 版比例、清晰的脸部和干净的服饰，但要保留成熟的构图和一点冷静的叙事感，避免幼儿卡通、表情包或过度卖萌。

## 外形锚点

每张图不必把所有特征都写满，但应保持以下识别方向：

- 一位精致、可辨认的 Q 版鲸鱼娘作为主要角色。
- 蓝色系或蓝灰系的鲸鱼特征，例如耳鳍、尾鳍、背鳍、鲸鱼轮廓或海洋色调。
- 头发、脸部、手部和服饰边缘要清楚，人物不能被道具遮成一团。
- 眼神和身体方向要服务于正在发生的事件。
- 轮廓可以带一点轻手绘抖动，但人物结构不能像草稿。
- 服饰和配件保持简洁，不为了可爱而叠加大量蝴蝶结、徽章、玩偶和海洋饰品。

不要把鲸鱼娘固定成一种姿势。她可以托住、拖拽、修补、分拣、守门、测量、接住、递交、打开、按住或回收，但动作必须来自正文主题。

## 角色事件规则

生成前用一句话写清楚：

> 鲸鱼娘正在对什么东西做什么，因此读者看见了什么关系。

例如：

- 鲸鱼娘把混乱的蓝色线团穿过一枚小孔，只让一条可用路径落入收纳盒，因此表达筛选不是堆积。
- 鲸鱼娘在断开的浮桥中间缝回一枚结，因此表达承接需要补上缺口。
- 鲸鱼娘把一枚回声贝壳放回潮汐装置的入口，因此表达反馈会回到系统里。

如果这句话只描述“她站在海边微笑”或“她拿着一个标题牌”，说明角色没有承担核心动作。

## 小鲸鱼规则

- 默认 0 个。
- 只有在小鲸鱼能承担输入、反馈、陪伴、结果、尺度变化或因果关系时，才允许 1 个。
- 不能用小鲸鱼填补空白、平衡构图、增加可爱感或复制主体动作。
- 默认不出现 2 个以上小鲸鱼，也不出现一群鲸鱼。

## 鲸鱼元素的克制

鲸鱼相关形状或符号只保留在角色和真正参与叙事的物件上。禁止同时把鲸鱼印在杯子、电脑、围裙、笔记本、边框、气泡、角落贴纸、按钮和所有道具上。

一张图只需要一个鲸鱼娘主体；如果某个鲸鱼元素不承担动作、状态或因果关系，就删掉它。

## 不应出现的角色结果

- 多个相似鲸鱼娘抢主体。
- 人物只做摆拍、挥手、比心或站立展示。
- 人物被画成模糊剪影、火柴人、满身辅助线或全身未完成草稿。
- 过度露骨、低龄化、性感化或与正文无关的视觉设定。
- 角色脸部、手部、尾鳍与道具的接触关系不清楚。
- 鲸鱼娘变成一个被贴在信息卡边上的 logo。
