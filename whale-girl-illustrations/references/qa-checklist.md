# 鲸鱼娘配图 QA 清单

生成、编辑或交付前检查。任一必过项失败，都应重排、局部编辑或重生成。

## 画布和模式

- [ ] 最终输出严格 3:4 竖版，不是默认 2:3，也没有被错误裁切。
- [ ] 如果是小红书图文，尺寸按 1080×1440 处理，关键标题和数据没有贴近边缘或底部遮挡区。
- [ ] 已根据用户要求选择内容卡片模式或场景隐喻模式。
- [ ] 默认只生成一张；若是组图，每张都有独立主题和独立构图。
- [ ] 小红书首图、轮播页和单张内容卡片没有混用错误职责；首图不是正文缩略版，内容页不是重复封面。

## 文字和信息

- [ ] 只提炼正文约 20%–30% 的核心语义，没有搬运全文。
- [ ] 用户指定的标题、项目名、星数、数字和 CTA 没有被擅自改写或发明。
- [ ] 内容卡片模式有足够的正文信息，不能退化成“一个大角色 + 0–4 个标签”。
- [ ] 内容卡片模式的标题、副标题、2–4 个信息区和可选 CTA 有清晰层级，但没有做成完整表格或仪表盘。
- [ ] 场景隐喻模式确实只保留一个核心判断、一个动作和一个结果，短标签确有必要。
- [ ] 中文不可靠时已计划或完成后期排版，而不是接受乱码和错误数字。

小红书具体检查见 `references/xhs-qa.md`；小红书任务必须同时执行该清单。

## 鲸鱼娘参考和比例

- [ ] 生成时实际使用了 `assets/whale-girl-reference/` 中的角色参考图。
- [ ] 保留蓝发、白色蕾丝发箍、侧边蓝色蝴蝶结、鲸鱼鳍耳朵、深蓝白色女仆装和蓝色鲸鱼尾巴。
- [ ] 角色脸部、眼睛、手、服饰、尾巴和动作接触点清楚，没有全身草稿化。
- [ ] 内容卡片模式角色通常约占 20%–35%，没有挤掉文字。
- [ ] 场景隐喻模式角色通常约占 35%–55%，没有和阀门/道具一起抢满画面。
- [ ] 默认只有一个鲸鱼娘主体；小鲸鱼角色 0–1 个。
- [ ] 小鲸鱼涂鸦最多一到两个且有表达作用，没有把鲸鱼印在杯子、电脑、围裙、边框和所有道具上。

## 灵性和构图

- [ ] 画面有不对称的阅读节奏，不是规整模板。
- [ ] 鲸鱼娘有可读的神态、视线和姿势，不是通用站立立绘。
- [ ] 有少量边框、标题底刷、气泡、下划线、箭头或纸感，手绘感主要在辅助元素上。
- [ ] `content-card-spirit.png` 的参考只影响气质和层级，没有复制其具体文字、姿势或道具。
- [ ] 文字、角色和道具之间有关系，阀门/磁盘/垃圾文件没有被放大成第二主角。

## 背景和颜色

- [ ] 背景是接近白色的非常浅暖白和轻纸感。
- [ ] 没有明显深黄、灰色、棕色、脏旧纹理或厚重颗粒。
- [ ] 深蓝/黑负责结构和主要文字，蓝色负责主体和状态，红橙只强调少数关键结论。

## 反 PPT、品牌洁净和交付

- [ ] 没有等宽卡片墙、九宫格、仪表盘、密集流程节点或图标清单。
- [ ] 不能因为“反 PPT”而误删用户明确要求的有效文字区。
- [ ] 没有 `by ian and 小黑`、签名、水印、二维码或未经要求的品牌标记。
- [ ] 保存到明确的 workspace 资产路径，未覆盖已有图片。

## 失败信号和修复顺序

1. 比例错误：重新按 3:4 排版，不要最后拉伸。
2. 文字太少：切换到内容卡片模式，先放标题、事实和核心亮点，再缩小角色。
3. 文字太满：删除背景和重复解释，保留核心信息，不要删除用户指定字段。
4. 角色太大：将人物放到右侧/右下并缩至 20%–35%；道具同步缩小。
5. 角色不像参考图：重新传入 neutral 参考，再用 smile/wave 补表情或动作。
6. 失去灵性：恢复不对称布局、气泡、手写底刷、神态和少量节奏涂鸦。
7. 太像 PPT：删掉等宽网格和统一图标，但保留有层级的手绘内容区。
8. 背景太黄/太灰或人物太草稿：先改底色和人物完成度，再调整装饰.
