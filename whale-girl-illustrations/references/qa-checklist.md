# 鲸鱼娘配图 QA 清单

生成、编辑或交付前逐项检查。任一必过项失败，都应重构或局部编辑后再交付。

## 必过项

### 比例和画布

- [ ] 最终输出是严格 3:4 竖版。
- [ ] 没有把 2:3 当作默认结果，也没有在导出时被裁成横版。
- [ ] 单图的主体、标签和留白都适配竖版，不是把横版内容硬塞进来。

### 信息量和文字密度

- [ ] 图片只提炼正文约 20%–30% 的核心信息。
- [ ] 只有一个核心判断、一个主要事件或一个核心隐喻。
- [ ] 默认没有超过 4 个短标签，每个标签足够短且确有必要。
- [ ] 没有正文段落、完整步骤、表格、图例、目录或小字说明。
- [ ] 文字没有替代本应由鲸鱼娘动作表达的关系。

### 角色和事件

- [ ] 默认只有一个主要鲸鱼娘主体。
- [ ] 小鲸鱼为 0 个，或只有 1 个且有明确表达作用。
- [ ] 鲸鱼娘正在参与核心事件，而不是摆拍、站角落或贴在卡片旁。
- [ ] 手、视线、身体方向、尾鳍和道具的关系清楚。
- [ ] 人物保持精致 Q 版完成度，没有全身草稿化、模糊或潦草到不可辨认。
- [ ] 没有因为装饰需要而重复添加鲸鱼图案。

### 风格和颜色

- [ ] 背景是接近白色的非常浅暖白和轻纸感。
- [ ] 背景没有明显深黄、灰色、棕色、脏旧纹理或厚重颗粒。
- [ ] 深蓝或黑色负责结构，蓝色负责主体和状态，红橙只强调关键结论。
- [ ] 边框、标题底刷、气泡、箭头和 doodle 克制，并服务于画面关系。
- [ ] 手绘感主要出现在辅助元素、道具和纸张质感上，人物仍然精致。

### 反 PPT 和品牌洁净

- [ ] 第一眼是有事件的正文插画，不是 PPT 信息卡、课程页或仪表盘。
- [ ] 没有规整卡片墙、九宫格、密集节点、图标清单或正式流程图。
- [ ] 没有 `by ian and 小黑`、签名、水印、二维码或未经要求的品牌标记。
- [ ] 留白仍然可见，装饰没有压过角色和核心动作。

## 失败信号与修复顺序

1. 比例错误：先重新设定 3:4 画布并重排主体，不要只在最后拉伸。
2. 文字过多：删掉次要解释，把结果交回正文；保留 0–4 个短标签。
3. 角色太多：删除重复鲸鱼娘和没有表达作用的小鲸鱼。
4. 角色像摆拍：重写“鲸鱼娘正在做什么”，让她与阻力、输入或结果发生接触。
5. 太像 PPT：去掉标题栏、卡片、规整箭头和图标网格，改成一个连续物理场景。
6. 人物太草稿：保留辅助元素的手绘质感，重新绘制脸部、手部、服饰和尾鳍。
7. 背景太黄或太灰：改为接近白色的浅暖白，降低底色饱和度和对比度。
8. 鲸鱼元素太满：删掉杯子、电脑、边框和角落里的重复鲸鱼符号，只保留有叙事作用的元素。

## 交付门槛

合格结果应满足：读者能看见鲸鱼娘正在做一件具体的事；能在很短时间内理解一个核心意思；能感到一点轻手绘的温度；同时不会误以为这是课程页、信息卡或品牌水印图。
