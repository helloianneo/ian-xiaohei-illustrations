# 鲸鱼娘 QA 清单

生成后检查。任一必过项失败，都应重生成或做一次针对性编辑。

## 画布和风格

- [ ] 严格 3:4 竖版，不是默认 2:3。
- [ ] 背景是接近白色的非常浅暖白，不明显发黄、发灰或脏旧。
- [ ] 有深蓝轻手绘外围框线、淡蓝文字底纹或下划线，并使用少量气泡/涂鸦/箭头表达关系。
- [ ] 使用了 `assets/whale-girl-reference/` 中的实际鲸鱼娘参考图。
- [ ] 鲸鱼娘的脸、眼睛、手、发箍、蝴蝶结、女仆装、鲸鱼耳鳍和尾巴清楚。

## 信息量和层级

- [ ] 画面只有一个主主题和一个视觉锚点，其他内容都围绕它服务。
- [ ] 信息丰富模式确实有标题、可选副标题、3–5 个相关信息区和更充足的短文案；不是只有一行标题加一个角色。
- [ ] 信息丰富模式大致包含 10–18 个短文本单元，正文被拆成短行、短句或项目符号；没有完整文章和密集不可读的小字墙。
- [ ] 每个信息区只有一个小标题和 1–3 行短说明，重点明确，区块之间有留白。
- [ ] 用户提供的项目名、数字、版本、星数、日期和结论没有被擅自发明或改写。
- [ ] 标题清楚醒目但没有占据画布上方大半；没有自动添加“Workflow”“系统架构图”等结构名称。
- [ ] 信息区可以有手绘边框、编号、底刷、图标或气泡，但大小和位置有变化，不是等宽等高的模板网格。

## 角色和小鲸鱼

- [ ] 鲸鱼娘参与视觉锚点或核心动作，不是站在信息区旁边的装饰或贴纸。
- [ ] 信息丰富模式中鲸鱼娘通常占画面 25%–40%，没有把文字空间挤没。
- [ ] 默认 0–1 个小鲸鱼；如果主题确实涉及群体、尺度、反馈、水流、陪伴或连续动作，可增加到 2–4 个，必要时再增加。
- [ ] 每只小鲸鱼有明确的动作、尺度、反馈、陪伴或情绪作用。
- [ ] 没有把鲸鱼反复印在杯子、电脑、围裙、边框、气泡和所有道具上。

## 颜色和表达

- [ ] 深蓝/黑负责结构，蓝色负责角色和状态，红橙只强调少数重点。
- [ ] 手绘感体现在人物动作、线条、短文字、底纹、气泡和道具关系上，不是人物全身草稿化。
- [ ] 没有商业 PPT 风格、后台仪表盘、UI 界面、商业扁平插画、儿童涂鸦、塑料 3D、强阴影或渐变。
- [ ] 没有 `by ian and 小黑`、签名、水印、二维码或未经要求的品牌角标。

## 失败信号和修正顺序

1. 比例错误：重新生成严格 3:4。
2. 文字太少：切换到信息丰富模式，补上 2–3 个与主题直接相关的信息区、短标题和短说明；不要只把鲸鱼娘放大。
3. 角色太大：把鲸鱼娘缩到画面约 25%–35%，把空间还给文字和信息区。
4. 文字太挤：删掉重复句和非核心数字，把每区压成 1–3 行，增加区块间留白。
5. 太像 PPT：改变信息区大小、位置和边框形状，保留一个主视觉锚点；不要删到只剩标题和角色。
6. 角色像贴纸：让鲸鱼娘操作、搬运、观察、修补或回应主要物件。
7. 太普通：换一个当前文案专属的低科技隐喻或道具关系，不增加无关信息框。
8. 小鲸鱼太少：只有在确实有尺度、反馈、陪伴或连续动作时增加；不为装饰硬塞。

## 交付判断

合格结果应该像可收藏的小红书手绘内容页：读者能读到多条有用信息，标题和区块层级清楚，鲸鱼娘仍然在做与主题有关的事，画面还有呼吸感。如果第一眼像模板化 PPT、等宽卡片拼贴、密集说明书或角色贴纸，就不合格。
