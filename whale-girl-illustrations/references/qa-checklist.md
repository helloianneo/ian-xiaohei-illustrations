# 鲸鱼娘 QA 清单

生成后检查。任一必过项失败，都应重生成或做一次针对性编辑。

## 必过项

- [ ] 严格 3:4 竖版，不是默认 2:3。
- [ ] 背景是接近白色的非常浅暖白，不明显发黄、发灰或脏旧。
- [ ] 有深蓝轻手绘外围框线、淡蓝文字底纹或下划线，并使用少量气泡/涂鸦/箭头表达关系。
- [ ] 使用了 `assets/whale-girl-reference/` 中的实际鲸鱼娘参考图。
- [ ] 鲸鱼娘参与核心动作，不是站在旁边的装饰或贴纸。
- [ ] 一张图只讲一个核心动作、结构、状态或隐喻。
- [ ] 主体组约占 40%–60%，保留一块安静留白。
- [ ] 中文标注短小、可读，通常 3–8 处；没有完整文章或密集说明书。
- [ ] 深蓝/黑负责结构，蓝色负责角色和状态，红橙只强调少数重点。

## 小鲸鱼

- [ ] 默认 0–1 个小鲸鱼；如果主题确实涉及群体、尺度、反馈、水流、陪伴或连续动作，可增加到 2–4 个，必要时再增加。
- [ ] 每只小鲸鱼有明确的动作、尺度、反馈、陪伴或情绪作用。
- [ ] 没有把鲸鱼反复印在杯子、电脑、围裙、边框、气泡和所有道具上。

## 失败信号

- [ ] 没有巨大左上角标题或“Workflow / 系统架构图 / 常见坑”等结构名称。
- [ ] 没有 PPT、课程课件、等宽卡片墙、九宫格、正式流程图或 UI 界面。
- [ ] 没有纯角色立绘；鲸鱼娘正在做事，并且动作能解释主题。
- [ ] 没有商业扁平插画、儿童涂鸦、塑料 3D、强阴影、渐变或脏旧纸。
- [ ] 没有 `by ian and 小黑`、签名、水印、二维码或未经要求的品牌角标。

## 文字和角色

- [ ] 用户明确提供的短标题、项目名和数字没有被擅自改写或发明。
- [ ] 长文已经压缩为一个核心意思和少量短标注。
- [ ] 鲸鱼娘的脸、眼睛、手、发箍、蝴蝶结、女仆装、鲸鱼耳鳍和尾巴清楚。
- [ ] 手绘感体现在人物动作、线条、短文字、底纹、气泡和道具关系上，不是人物全身草稿化。

## 迭代顺序

1. 比例错误：重新生成严格 3:4。
2. 太像 PPT：删掉标题、卡片和等宽框，改成一个手绘场景。
3. 角色像贴纸：让鲸鱼娘操作、搬运、观察、修补或回应主要物件。
4. 太复杂：删掉物件和标注，只保留一个动作与 3–5 个关键短词。
5. 太普通：换一个当前文案专属的低科技隐喻，不增加信息框。
6. 小鲸鱼太少：在确实有尺度、反馈、陪伴或连续动作时增加 1–3 个；不为装饰硬塞。

## 交付判断

高质量图应该让读者先觉得“有点怪”，然后 1 秒内看懂核心关系。如果第一眼像教程页、信息海报、可爱角色海报或角色贴纸，就不合格。
