# 视觉提炼与模式判断

## 先区分两种预算

“只提炼正文约 20%–30%”指选择正文的核心语义，不指把画面压成四个标签。先删掉背景、例外、重复论证和不影响理解的细节，再根据模式决定这些核心语义需要多少文字来表达。

- 场景隐喻模式：通常是一句判断、一个动作、一个关系和一个结果，文字少。
- 内容卡片模式：可以用标题、副标题、2–4 个短内容区、一个观点/气泡和一个 CTA 表达多个相关核心信息，但仍然只取正文最重要的 20%–30%，不搬运全文。
- 小红书轮播模式：整篇只选择 20%–30% 的核心语义，但把它分配到不同页面；每页只承担一个核心意思，不能因为分页就把全文逐段搬上去。

## 提炼步骤

### 1. 找主线

写出文章最值得被看见的一条主线：判断、冲突、前后变化、体验结论、工具价值或读者行动。

### 2. 分出内容类型

把用户要求分成：

- 必须原样出现的标题、项目名、星数、数字和 CTA。
- 可以压缩的介绍、特色和体验。
- 应该留在正文而不是图片里的背景材料。

### 3. 选择模式

小红书路由：

- “封面/首图/一张配图”：小红书首图模式。
- “项目介绍/特色/亮点/星数/怎么用”：小红书轮播模式，除非用户明确只要单图。
- “做成一组/多张/轮播”：小红书轮播模式，先规划页码和页面职责。
- “正文配图/文章插图/表达一个观点”：单张内容卡片或正文场景隐喻模式。

使用内容卡片模式的信号：

- 用户要求“项目介绍 + 特色亮点 + GitHub 星数”等并列内容。
- 用户提供了开头文案，要求图片本身可独立阅读。
- 用户强调“要有一定文字量”或给了一个内容卡片参考图。

使用场景隐喻模式的信号：

- 用户只要求表达一个抽象观点、一个痛点或一个动作。
- 文字越多越会削弱唯一隐喻。
- 用户明确要少字或纯正文插图。

### 4. 形成画面草稿

内容卡片模式写：

```text
标题：
副标题：
核心信息区 1–4：
观点/气泡：
CTA（可选）：
鲸鱼娘神态和动作：
角色位置与比例：
```

场景隐喻模式写：

```text
核心判断：
鲸鱼娘正在做什么：
唯一物理隐喻：
可见结果：
必要短标签：
```

如果内容卡片草稿接近完整文章，继续压缩语义；如果场景隐喻草稿让角色或阀门占掉文字空间，切换到内容卡片模式或缩小主体，不要硬塞。

## 单图和拆组图

默认一张 3:4 图。小红书语境下，如果用户要求介绍多个独立方面，可以拆成轮播；其他情况只有在以下条件同时成立时才拆组图：

1. 各主题有独立的核心判断和独立的视觉关系。
2. 强行放在一张图中会让文字不可读或角色/道具失去比例。
3. 用户需要组图，或正文确实存在并列章节。

拆组图时每张仍然独立构图、严格 3:4、一个鲸鱼娘主体优先，不做连续漫画长页或九宫格。先规定整组风格锁：边框、标题底刷、主体色、字体层级、角色参考和装饰预算；再写每页内容。

## 精确文字处理

用户给出的标题、项目名、数字和 GitHub 数据属于事实字段，不能改写或凭空补全。图像模型容易错字时，优先生成留白和手绘结构，随后用后期排版叠加文字。不要因为模型容易错字，就把用户明确要求的内容全部删掉.
