# 鲸鱼娘手绘正文配图

## 核心定位

为中文文章、帖子、项目介绍、工具推荐和方法论生成一张有创意、可读、带动作的 3:4 竖版手绘配图。目标是“白纸上的手绘解释图”，不是 PPT、信息卡片墙、商业海报或单独角色立绘。

工作方式沿用小黑 Skill 的稳定骨架：一张图只讲一个核心结构；鲸鱼娘必须做一件解释主题的事；每次根据当前文案重新发明画面，不复刻旧构图。

用户明确要求生成时，直接使用内置 `image_gen` 每张单独生成，不先展开复杂的轮播规划、信息架构或后期排版流程。

## 先读这些参考

按任务需要读取：

- `references/style-dna.md`：3:4 画布、背景、线条、颜色、文字和禁忌。
- `references/whale-girl-ip.md`：鲸鱼娘、小鲸鱼的身份、动作和数量规则。
- `references/composition-patterns.md`：可选结构和原创隐喻方法。
- `references/prompt-template.md`：单张生图提示词模板。
- `references/qa-checklist.md`：生成后检查和重生规则。

不需要读取或寻找布局示例。角色参考图只负责锁定鲸鱼娘身份：默认使用 `assets/whale-girl-reference/whale-girl-neutral.jpg`；只有需要笑脸或挥手动作时，才额外使用 `whale-girl-smile.jpg` 或 `whale-girl-wave.jpg`。

## 工作流

### 1. 消化文案

先读用户给出的正文、链接、截图或文案，提炼：

- 这张图唯一要表达的核心意思。
- 适合变成什么物理动作或视觉关系。
- 必须保留的少量项目名、数字或短标注。
- 哪些内容留在正文，不塞进图片。

不要平均解释全文。用户给了长文时，只选择一个认知锚点；不要自动把项目介绍拆成多个信息卡片。

### 2. 选择一个结构

从 `references/composition-patterns.md` 选择一个结构即可。不得把多个结构混成一张复杂海报。

### 3. 生成前写短策略

内部只写清楚：

```text
主题：
结构类型：
核心意思：
鲸鱼娘正在做什么：
小鲸鱼正在做什么（可选）：
主要物件：
3–8 个短中文标注（可选）：
```

### 4. 单张生图

按 `references/prompt-template.md` 生成一张严格 3:4 竖版图。必须把角色参考图作为 image reference 传给图像工具；不要只写“蓝色鲸鱼娘”而不传图。

### 5. 检查和迭代

生成后读取 `references/qa-checklist.md`。出现失败信号时，优先针对一个问题重生成或编辑，不要继续增加更多规则和元素。

## 不可违背的规则

- 默认严格 3:4 竖版，不接受默认 2:3。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- 鲸鱼娘必须参与核心动作，不能只是站在旁边或贴在信息区旁边。
- 鲸鱼娘是精致 Q 版主体；手绘感主要来自线条、文字、边框、底纹、气泡、箭头和道具关系，不能把人物画成全身草稿。
- 小鲸鱼默认 0–1 个；只有主题确实需要群体、尺度、反馈、水流、陪伴或连续动作时才增加到 2–4 个，必要时再按画面需要增加。每只都要有动作、尺度或情绪作用，不能把鲸鱼印在每个物件上。
- 背景必须是接近白色的非常浅暖白；保留深蓝手绘外围框线、淡蓝文字底纹、少量气泡和红橙重点。
- 用户提供的标题或项目名可以作为短手写标注，但不要自动做成巨大左上角标题；不要在图上写“Workflow”“系统架构图”等结构名称。
- 中文标注保持短小，通常 3–8 处；不要生成完整文章、说明书或密集小字墙。
- 禁止 PPT 信息图、等宽卡片墙、九宫格、正式流程图、UI 截图、商业扁平插画、塑料 3D、强阴影、渐变、脏旧纸和科技感界面。
- 禁止 `by ian and 小黑`、签名、水印、二维码和未经要求的品牌角标。

## 交付判断

高质量结果应让读者先看到一个有点奇怪但成立的鲸鱼娘动作，再在 1 秒内看懂核心关系。若第一眼像教程页、信息海报、可爱角色海报或角色贴纸，就不合格。
