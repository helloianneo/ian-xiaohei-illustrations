# Composition Patterns and Originality Rules

## Base structure types

Pick one structure. Don't mix too many.

### Workflow

Good for: input -> processing -> output, content production, AI workflows, automation chains.

How to draw: input on the left, Xiaohei or a weird machine processing in the middle, output on the right, orange arrows for the main flow.

### System close-up

Good for: information sources, filters, databases, renderers, a close-up of an agent system.

How to draw: only 3-5 core modules; Xiaohei takes part in one key action.

### Before-after contrast

Good for: chaos/order, manual/automatic, scattered/gathered, anxious/stable.

How to draw: chaos on the left, stability on the right, orange arrow in the middle. The character can be more exaggerated.

### Character states

Good for: user pain points, creator states, too many tools, information anxiety, stuck-to-running.

How to draw: 2-4 small states, one short label each.

### Concept metaphor

Good for: content factory, information warehouse, black box in your head, workflow machine, automated daily report.

How to draw: one big weird object or machine, a few inputs, one output. Make it memorable.

### Method layers

Good for: methodology frameworks, system levels, capability stacks, layered content systems.

How to draw: stacked boxes, not a formal pyramid; Xiaohei hauls bricks or builds off to the side.

### Map route

Good for: idea to launch, user journeys, content handoff paths, learning paths.

How to draw: one winding path, a few nodes, Xiaohei pulls a string along it or walks it.

### Mini comic panels

Good for: failure to success, the real process, venting, before-and-after-use change.

How to draw: 2-4 small scenes, one action per panel.

## Original metaphor method

Reinvent the metaphor from the current article every time. Never copy old images.

### Three steps

1. Swap the abstract concept for a physical action: getting stuck, leaking out, getting heavier, sorting, settling, fermenting, opening a door, folding, unpacking, flowing back.
2. Swap the system structure for a low-tech object: a broken machine, a cardboard box, a drawer, a water pipe, a mailbox, a weird dial, a scale, a well, a ladder, an odd workstation.
3. Give the action to Xiaohei: not standing off to the side, but stuck inside the machine, pulling the wrong wire, guarding the gate, hauling, patching, weighing, steadying the ladder, taking notes, stuffing things into some weird contraption.

### Object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, water pipe, ball of string, sluice gate, turntable, black box, hole punch, noodle press, clothesline, weird workstation.
- Pick only 1-2 per image. Don't pile them up.

### Xiaohei action pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, take apart, mark, recycle.
- The action must serve the core meaning — never absurd for absurdity's sake.

## Anti-copying rules

Don't open or replicate `assets/examples/` by default. Those images are for style calibration only: line density, white space, color restraint, Xiaohei's vibe.

Unless the user explicitly says "match this image / replicate this composition / adapt this example," don't reuse these old compositions directly:

- Conveyor belt with two breakpoints
- Xiaohei pulling the judgment lever inside a content machine
- Xiaohei turned into a funnel sorting traffic/trust/conversion
- Xiaohei slicing a material fish
- Xiaohei pulling a handoff path
- Xiaohei pulling three layers of information sources
- Three Xiaoheis: one with a megaphone, one building a bridge, one opening a door
- Xiaohei stamping a talk-track toolbox
- Xiaohei holding up a sign, eyeing a path of common pitfalls

Swap in a new metaphor even for same-family topics. A "handoff path" doesn't have to be a route — draw Xiaohei hooking a content tail onto a door handle. "One fish, many uses" doesn't have to be a fish — draw Xiaohei pressing one paper ball into several shapes.
