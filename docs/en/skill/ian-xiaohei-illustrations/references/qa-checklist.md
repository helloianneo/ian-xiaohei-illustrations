# QA Checklist

## Must-Pass Items

- 16:9 landscape.
- Clean white background.
- Xiaohei is in the frame.
- Xiaohei performs the core action, not just decoration.
- No rehash of an old example's composition — a new metaphor built for this article.
- The image is absurd, creative, and interesting.
- Simple and clean; the subject covers no more than ~60% of the frame.
- One image, one core structure.
- Annotations are few, short, and readable.
- Orange only for the main path or arrows.
- Red only for key points, problems, reminders, or results.
- Blue only for supplementary notes, feedback, or system state.

## Failure Signals

If any of these show up, regenerate or make a targeted edit:

- A title in the top-left corner like "Common Pitfalls / Workflow / System Architecture / Roadmap".
- Xiaohei looks like a mascot, a meme sticker, or a cute cartoon.
- The image looks like a PPT slide, course material, or a formal flowchart.
- Too many elements, too many arrows, too many nodes.
- Text turns into paragraphs of explanation.
- Paper texture, shadows, gradients, beige, or grain in the background.
- Real UI screenshots or tech-styled interfaces.
- Serious typos / garbled label text, or unreadable annotations.
- The image is too stiff — no absurd metaphor.
- Composition too similar to the old examples in `assets/examples/`.

## Iteration Moves

- Too ordinary: make Xiaohei the action subject and add one absurd but coherent metaphor.
- Too complex: cut nodes; keep one action and 3-5 short annotations.
- Too cute: emphasize deadpan, blank serious expression, not cute, not mascot.
- Too PPT: drop titles, borders, tidy grids, and excess arrows; redraw as a hand-drawn scene.
- Too close to an old example: keep the core meaning, swap the main object and Xiaohei's action.
- Text is wrong: prefer a targeted edit; if errors are widespread, regenerate and cut the annotation count.

## Ship Call

A high-quality image makes the reader think "that is a bit odd" first, then read the structure within 1 second.

If the first glance reads like a tutorial page instead of an absurd product sketch on white paper, it fails.
